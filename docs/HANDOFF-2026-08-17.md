1. 足あとシートの中 → 押さないと気づけない

`__tests__/place-context-bar-placement.test.ts` と

### 動作は正しいのに肥大する種類のバグ

`h3-js` も Clerk chunk も、**型チェック・テスト・lint を全部素通りする**。
バンドルサイズを実測しない限り気づけない。調べ方:

1. `curl` でHTMLを取り、`/_expo/static/js/web/*.js` を全部落として**サイズを並べる**
2. `npx expo export -p web --source-maps` して `.js.map` の
   `sources`/`sourcesContent` をパッケージ単位で集計すると内訳が出る
3. `grep -rln "<lib>" app/ components/ lib/ hooks/` で誰が引き込んでいるか辿る

### 外部URLは curl だけで判断しない

`twitter.com/intent` が curl で403を返したので犯人にしかけたが、
**実ブラウザでは正常**だった（ボット判定）。逆に近畿のライブカメラは
curlで200に見えて**実際はエラーページへリダイレクト**していた。
最終URLまで追う（`curl -sIL`）か、実ブラウザで開く。

### CDN_CACHE_EPOCH が効かないことがある

エポックを2回上げても直らなかった。真因は **`app/_layout.tsx` が
`theme/tokens` を import しておらず改名されなかった**こと。
「ほぼ全チャンクが tokens を import している」という前提から漏れていた。
現在は `_layout` がエポックを直接参照するので同じ穴は塞がっている。

切り分け方（親チャンクを連結して参照が1つか2つか見る）:

