### 白画面（2026-08-17 に実際に起きた・復旧済み）

本番の**全ページが真っ白**になった。症状は
`Refused to execute script` → `Requiring unknown module "2332"` → body が空。

原因は、あるチャンクURL（`?v=<sha>-<Date.now()>` 付き）に対して
**Cloudflare が SPA の HTML をキャッシュして配信し続けていた**こと
（`cf-cache-status: HIT`）。ブラウザは text/html を JS として実行できない。

**curl では両方とも正しい JS が返る**ため、実ブラウザで見ないと分からない。
切り分けはこれ:

```bash
cd "/c/Users/info/OneDrive/デスクトップ/Resilio/github/surechigai-romi.link" && node -e "const {chromium}=require('playwright');(async()=>{const b=await chromium.launch();const c=await b.newContext();const p=await c.newPage();p.on('response',r=>{if(r.url().includes('__common'))console.log(r.headers()['content-type'],r.url().slice(-60))});await p.goto('https://surechigai.kimito.link/',{waitUntil:'domcontentloaded'});await p.waitForLoadState('networkidle',{timeout:25000}).catch(()=>{});console.log('body文字数:',await p.evaluate(()=>document.body.innerText.length));await b.close()})()"
```

`content-type` が `text/html` なら当たり。対処は `bust-entry-cache.cjs` の
版数から `Date.now()` を外し、毎デプロイで新URLを作らないこと（実施済み）。
**ただし根本原因は CDN 側**なので、SHA だけの URL でも起こりうる。

## 4.5 kimito-link からの移植（2026-08-17 追加分）

技術スタックが違う（kimito-link は素の HTML／surechigai は Expo Router）ため
UIは移植できない。**検査ツールの層だけ**移植した。

| 移植したもの | 元 | 効果 |
|---|---|---|
| `pnpm check:doc-links` | `tools/check-doc-links.js` | リンク切れ21件を検出・全て修正 |
| `pnpm check:a11y` | `tests/node/test-axe-wcag-key-pages.js` | serious/critical 20件を検出・全て修正 |

どちらも**そのままでは使えず改良が要った**:
- リンク検査はルート基準のパスを解決しないと誤検知30件＞本物21件になる
- axe は SPA 用にハイドレーション待ちと 404 判定を足す必要がある

### この移植で見つかった本番の実害

- **本番全ページが白画面**だった（別途復旧済み。§4「白画面」参照）
- `role="tab"` を包む `tablist` が4ファイルすべてに無かった
- 幅480px未満でタブのアクセシブル名が消えていた
- ロゴ・マスコット画像に alt が無かった
- `textHint` がページ地で 4.31 と AA 未達（`semantic.ts` は
  「ライト地で AA 以上に統一」と宣言しているのに満たしていなかった）
- ブランドオレンジ `#DD6500` が12px文字でカード地 2.98

最終結果は **6ルートすべて違反0件**（`pnpm check:a11y` が exit 0）。

### expo-image の落とし穴

`<Image alt="...">` は **Web の通常表示では効かない**。
型定義には「alt は accessibilityLabel のエイリアス」とあるが、
`ExpoImage.web.tsx` の実装では通常表示の経路が `accessibilityLabel` しか
渡しておらず、`alt` はプレースホルダー経路専用。
**`accessibilityLabel` を使うこと**。空文字も falsy で属性ごと消える。

### 色を足すときの型

ブランド色（`DESIGN.md` 定義）は**値を変えない**。
小さい文字で AA に届かない場合は、文字専用の派生色を足す
（`kimitoOrange` はそのまま／`kimitoOrangeText` を新設）。
