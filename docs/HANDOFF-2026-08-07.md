## 今日直したもの（本番反映済み）

### Gate 1 Check が生まれてから一度も緑になっていなかった（`6b8517bb6`）
**200件の実行履歴すべて failure。7月6日まで遡って全部赤。**
`Deploy to Vercel` は緑だったので本番は無事だったが、**型チェックのゲートが常時赤＝誰も見ない状態**で、
本物の退行を隠し続ける寸前だった。

**真因**: Expo の Web 向け型拡張（`position:"fixed"` / Pressable の `hovered` / `*.css` モジュール）は
`/// <reference types="expo/types" />` で供給される。この参照を持つ `expo-env.d.ts` は
**Expo の自動生成物で `.gitignore` 済み**（ファイル自身に "should be in your git ignore" と書いてある）。
CI のクリーンチェックアウトには存在しないので、`tsconfig.json` の `include` が挙げていても参照が繋がらず、
Web 向け型が丸ごと欠落して `pnpm check` が落ちていた。

**なぜ気づけなかったか**: ローカルには生成済みファイルが残っているため `pnpm check` は緑。
**ローカルの緑は根拠にならない**という既知の教訓がそのまま出た形。

→ 同じ参照を**追跡ファイル** `types-expo-env.d.ts` に置いて恒久解決（`expo-env.d.ts` は
Expo が上書きするので触らない）。**変異テストで実効性確認済み**（両ファイル退避で13件エラー）。
型チェックでは検出できないため退行防止テスト3件を追加。


### サムネ・@ハンドルが出ない問題（`5912a07ff` / `c80d151b7`）

**真因**: `getMyEncounters` が `users.name`（表示名「君斗りんく@動員ちゃれんじ」）を
`twitterUserCache.twitterUsername`（Xハンドル・英数字15文字以内）と照合していた。
**日本語表示名では構造的に永久ヒットしない。**

**「前も見た」は正確だった** — zukan 側で**7回**修正されていた同じ問題
（`975917fe6` / `a1a5ab25d` / `a60c5cb35` / `d05110fb6` / `c953c2a8d` / `492b79c64` / `3881c1915`）。
反映されなかったのは「関数は共通化されたが呼ばれていない」構図。

→ zukan で実運用中の `resolveTwitterCacheForUser` に委譲。正規表現のコピー実装も除去。
モーダルはアイコンをハードコードし、Xリンクも表示名から組んで**必ず404**だった。
契約テストに★退行防止3件を追加し、**変異テストで実効性を確認済み**。

## 絶対にやってはいけないこと

1. **`allowNavigation` に OAuth ドメインを足す** — Google は WKWebView の OAuth を
   `disallowed_useragent` で明示拒否し、Apple も iOS 17 で Sign in with Apple を塞いだ。
   **足すとログインが壊れる**（外部ブラウザには出なくなるが）
2. **新規コンポーネントで `useUser()` を呼ぶ** — ClerkProvider が動的 import されるため
   chunk 解決前に描画されるとアプリ全体が落ちる（2026-07-31 / 08-01 に2度本番が白画面）。
   `window.Clerk` の任意参照にすること
3. **サーバーの tRPC 内で fetch を投げっぱなしにする** — Vercel Serverless は未解決 Promise が
   あると関数を終了しない。`void` も `.catch()` も効かない
4. **`twitterUserCache.expiresAt` を表示側で見る / `cron.ts` の削除処理を動かす** —
   出ていたアバターが消える。期限判定は「外部APIを省いてよいか」だけに使う
5. **`partnerName`（表示名）をハンドルとして扱う** — 8回目の再発になる。
   検証は `normalizeTwitterUsername` に一本化
6. **`types-expo-env.d.ts` を消す / `expo-env.d.ts` を commit する** —
   前者を消すと**CIだけが赤くなりローカルでは再現しない**（原因が極めて見つけにくい）。
   後者は Expo が上書きするので commit しても無意味。
   CI の型エラーを調べるときは `mv expo-env.d.ts` で退避してから `npx tsc --noEmit` すれば再現できる
