### 2. スプラッシュ画像に濃紺の四角が浮いていた ★ユーザー指摘の実物

**ユーザー指摘**「スプラッシュ画面がひどい」の正体。**画像を目視するまで気づけなかった。**

薄青(`#E2EDF7`)の地に、**濃紺の正方形**が小さく浮いていた。
`compose_site_icon()` はアプリアイコン用に「ネイビーの正方形」を返すので、
それを薄青のスプラッシュ地にそのまま貼ると四角い箱に見える。
大きさも短辺の28%（画面高の約1/10）しかなかった。

- スプラッシュに貼るときだけ**角を丸める**（iOSアイコンと同じ 22.37%）
- **0.28 → 0.62**（短辺比）。縦画面で高さの約29%
- 背景色 `#E2EDF7` は**変えない**（manifest.background_color かつアプリ本体の地色。
  揃えておくと起動→本体で色が変わらない）
- `splash-icon.png` を **200 → 600px**。`app.config.ts` の `imageWidth: 200` は
  ポイント指定で3x端末では600px描画のため、200px素材だと3倍に引き伸ばされていた。
  `imageWidth` は変えない（レイアウトを変えないため）

ネイティブ側は背景が `#00427B` なので四角は見えず無傷だった（経路が2本ある例）。
本番から画像を落として目視で修正を確認済み。

### 3. 却下の原因を検出できない検査が、誰にも実行されていなかった ★最も重い

`check-native-unsafe-dom.mjs` は **iOS 518 却下**（Hermes に `addEventListener` が無く
起動時に全画面エラー）を捕まえるための検査。しかし:

- **`pnpm check` にも CI にも未登録**（grepで確認）＝誰も実行していない
- 実行すると **NG 2件**を出すが、追試するとどちらも**誤検知**
- そして冒頭コメントに自ら「**本物の不具合を検出できない**」と書いてあった

**変異テストで実証**: 却下当時の姿（Platform ガードを外した状態）を再現したところ、
検査は **OK と報告した**。捕まえるべきものを捕まえられていなかった。

**真因**: 「危険な行の60行手前までにガードがあれば OK」としていたため、
**別の関数やモジュール定数のガードを根拠に見逃していた**。
実際 `app/_layout.tsx` では24行上のモジュール定数
`const INITIAL_WEB_PATH = Platform.OS === "web" && ...` を理由に、
別関数内の未ガードな `window.addEventListener` が OK と判定されていた。

- スコープを**内側から外側へ**辿り、浅いインデントの関数開始ごとにガードを探す形へ
- ガード済み `useEffect` のクリーンアップは通し、別関数のガードは根拠にしない
- Web判定ヘルパー（`isWeb()` 等）による早期returnも認識（誤検知2件の解消）
- `findClickableXButton` に自前ガードを追加（呼び出し元の事情に安全を委ねない）
- **`pnpm check` に組み込み**

**検証**: 却下当時の姿を再現すると **NG 4件で exit 1**、戻すと exit 0。

コミット: `16fa4c856`

## 追加ラウンド（OGP画像の作り込み）

### 6. 県が分かる人の共有画像が真っ白だった（0バイト）★最も影響が大きい

**2026-08-19 の `6545707c6` から2日間、本番で壊れていた。**

`?pref=長野県` のように県が解決できる共有URLで、OGP画像が
**200 / image/png のまま 0 バイト**になっていた。全都道府県で再現。
存在しない県名では正常に描画されたため、夜景の「県の位置に灯をともす」
分岐だけが壊れていると特定できた。

**真因**: その分岐が `border: undefined` を渡していた。
Satori は undefined の border で描画に失敗し空の応答を返す。
avatar がある場合は `5px solid` が入るので通っていたため、
**Xアイコンを取得できた人は正常・できない人は真っ白**という
分かりにくい壊れ方をしていた。

**HTTPステータスでは絶対に気づけない**（200 かつ image/png）。
size=0 を見て初めて分かった。

→ `pnpm check:ogp`（`scripts/qa/check-ogp-renders.mjs`）を新設。
8ケースを叩き、サイズと PNG ヘッダの寸法まで検証する。
実際に起きた「200/image/png/0バイト」を NG と判定することを確認済み。

コミット: `ff732b87c`（修正） / `ac0a91413`（検査）

### 7. 場所が分からないのにピンを打っていた

ラベルは「日本のどこか」なのに**日本地図の中央にピンが描かれていた**。
分からないのに分かっているように見える矛盾した絵。

このプロダクトの中心価値は「正確な場所を残して後でたどれる」こと。
場所が分からないなら**分からないと正直に見せる**方が誠実で、
ブランドの主張とも一致する。

判断は `lib/ogp/pin-visibility.ts` の純粋関数へ切り出してテストで固定した
（描画コードの中にあったため守れず、長く見逃していた）。

コミット: `6c1fd363e`
