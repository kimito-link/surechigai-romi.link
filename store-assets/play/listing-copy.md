# Google Play ストア掲載情報

`scripts/play-fill-listing.mjs` がこのファイルを読む。
**`## 詳しい説明` の直後の ``` フェンスの中身**が Play の「詳しい説明」になる
（フェンスが無いと起動直後に例外で落ちるので、見出しとフェンスは消さないこと）。

文面は App Store に登録済みの説明文（`ja` ロケール）と同一に保っている。
両ストアで内容がズレると、どちらが正か分からなくなるため。
iOS 側の正本は App Store Connect で、変更したらここも合わせる。

- 詳しい説明: 4000文字以内
- 簡単な説明: 80文字以内（`app.config.json` の `identity.shortDescription`）
- タイトル: 30文字以内（`app.config.json` の `identity.displayName`）

## 詳しい説明

```
すれ違った場所を記録して、あとからその思い出の場所をたどれるアプリです。

■ 足あとを残す
チェックインすると、いまいる場所が正確な座標で記録されます。
市区町村よりも細かい精度なので、あとで実際にその場所へ戻れます。

■ すれ違いを知る
同じ場所を通った人とのすれ違いが記録されます。
過去30日にさかのぼって照合するので、時間がずれていても出会えます。

■ 日本地図の図鑑
訪れた都道府県が色づいていきます。
日本地図を自分の足あとで埋めていく楽しみがあります。

■ 集まり
イベントの予定とライブ中がひと目で分かります。

■ 交流はXで
アプリ内にDMはありません。やりとりはX（旧Twitter）にお任せします。
ログインもXアカウントまたはAppleアカウントだけ。新しいパスワードは不要です。

■ 見せ方は選べる
足あとの公開範囲は4段階から選べます。
「非公開」「リンクを知っている人」「すれ違った人だけ」「公開」。
自宅の場所を隠す設定や、最長72時間の記録休止もできます。

記録と再訪は、ずっと無料です。
```

## 簡単な説明（参考・正本は app.config.json）

```
会いたい君がいる現在地。足あとを残して、あとからその場所へ。
```
